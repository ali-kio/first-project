# Unit Converter

A beginner-friendly Python command-line unit converter.

## Features

- Convert **length** values between `m`, `km`, `mi`, and `ft`
- Convert **weight** values between `g`, `kg`, `lb`, and `oz`
- Convert **temperature** values between `c`, `f`, and `k`
- Convert multiple values in one run using a simple loop

## How to run

1. Make sure Python 3 is installed.
2. In this repository directory, run:

```bash
python main.py
```

3. Follow the prompts:
   - Choose a category
   - Choose input and output units
   - Enter a value
   - View the converted result
